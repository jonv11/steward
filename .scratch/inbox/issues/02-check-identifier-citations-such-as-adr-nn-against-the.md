# 02 — Check ADR-NN style citations against the artifacts that define them

Status: needs-triage
Category: enhancement

> *This was generated by AI.*

**Problem:** Steward checks links between files, but not identifiers cited in plain text. mpes cites decisions as `ADR-NN` in code comments, docs and Issues. Its Issues name Efforts in frontmatter. A misspelt or retired ID passes `steward check`. mpes keeps a shell script (`Tools/check-consistency.sh`) as a separate gate only for this: every cited `ADR-NN` must exist as a decision record, and every `effort:` must name an existing Effort.

**Expected:** a rule that resolves identifier references against a set of artifacts. Configuration would give a pattern (e.g. `ADR-\d+`), the file globs to scan (including non-Markdown sources), and where valid IDs come from (a frontmatter `id` field of an artifact family, or directory names). It reports each unresolved citation with path and line, scoped and baselined like other rules. STWD-023 already knows artifact identities, so this could build on it.
